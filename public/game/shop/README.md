# Space News Shop Assets

Diretórios oficiais para cosméticos:

- `public/game/shop/accessories/front/`
  - acessórios da frente da nave
  - usar pares: `front-nome.png` e `front-nome-dodge.png`

- `public/game/shop/accessories/middle/`
  - acessórios do meio/corpo da nave
  - usar pares: `middle-nome.png` e `middle-nome-dodge.png`

- `public/game/shop/pets/`
  - pets flutuantes
  - usar 4 frames: `pet-nome-0.png`, `pet-nome-1.png`, `pet-nome-2.png`, `pet-nome-3.png`

- `public/game/shop/recolors/`
  - recolors da nave principal
  - usar pares: `recolor-nome-idle.png` e `recolor-nome-dodge.png`

Observação: para o item aparecer na loja, além do arquivo existir aqui, precisa existir entrada em `SHOP_ITEMS` dentro de `app/jogo/page.tsx`.
